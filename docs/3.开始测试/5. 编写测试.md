## 二、完善测试用例

### 2.1 添加测试数据

首先，我们需要在测试前准备一些数据。使用 `@BeforeEach` 注解在每个测试前执行：

```java
@BeforeEach
public void setUp() {
    // 清理旧数据
    QuestionExample example = new QuestionExample();
    questionMapper.deleteByExample(example);
    
    // 创建测试数据
    Question question1 = new Question();
    question1.setTitle("如何学习 Spring Boot？");
    question1.setContent("求指导...");
    questionMapper.insert(question1);
    
    Question question2 = new Question();
    question2.setTitle("Java 和 Kotlin 有什么区别？");
    question2.setContent("好奇...");
    questionMapper.insert(question2);
}
```

### 2.2 完善测试断言

更新测试方法，验证返回数据：

```java
@Test
void user_can_view_questions() throws Exception {
    // when
    this.mockMvc.perform(get("/questions"))
    // then
            .andExpect(status().isOk())
            .andExpect(jsonPath("$.code").value(200))
            .andExpect(jsonPath("$.data").isArray())
            .andExpect(jsonPath("$.data").isArray(hasSize(2)))
            .andExpect(jsonPath("$.data[0].title").value("如何学习 Spring Boot？"))
            .andExpect(jsonPath("$.data[1].title").value("Java 和 Kotlin 有什么区别？"));
}
```

### 2.3 完整测试类

```java
package com.nofirst.spring.tdd.zhihu.startup.integration.questions;

import com.nofirst.spring.tdd.zhihu.startup.BaseContainerTest;
import com.nofirst.spring.tdd.zhihu.startup.mapper.QuestionMapper;
import com.nofirst.spring.tdd.zhihu.startup.model.domain.Question;
import com.nofirst.spring.tdd.zhihu.startup.model.domain.QuestionExample;
import org.junit.jupiter.api.BeforeAll;
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.TestInstance;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.test.web.servlet.MockMvc;
import org.springframework.test.web.servlet.setup.MockMvcBuilders;
import org.springframework.web.context.WebApplicationContext;

import static org.hamcrest.Matchers.hasSize;
import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.get;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.jsonPath;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.status;

@TestInstance(TestInstance.Lifecycle.PER_CLASS)
public class ViewQuestionsTest extends BaseContainerTest {

    private MockMvc mockMvc;

    @Autowired
    private WebApplicationContext context;

    @Autowired
    private QuestionMapper questionMapper;

    @BeforeAll
    public void setupMockMvc() {
        mockMvc = MockMvcBuilders
                .webAppContextSetup(context)
                .build();
    }

    @BeforeEach
    public void setUp() {
        // 清理旧数据
        QuestionExample example = new QuestionExample();
        questionMapper.deleteByExample(example);
        
        // 创建测试数据
        Question question1 = new Question();
        question1.setTitle("如何学习 Spring Boot？");
        question1.setContent("求指导...");
        questionMapper.insert(question1);
        
        Question question2 = new Question();
        question2.setTitle("Java 和 Kotlin 有什么区别？");
        question2.setContent("好奇...");
        questionMapper.insert(question2);
    }

    @Test
    void user_can_view_questions() throws Exception {
        // when
        this.mockMvc.perform(get("/questions"))
        // then
                .andExpect(status().isOk())
                .andExpect(jsonPath("$.code").value(200))
                .andExpect(jsonPath("$.data").isArray())
                .andExpect(jsonPath("$.data", hasSize(2)))
                .andExpect(jsonPath("$.data[0].title").value("如何学习 Spring Boot？"))
                .andExpect(jsonPath("$.data[1].title").value("Java 和 Kotlin 有什么区别？"));
    }
}
```

## 四、让测试通过

### 4.1 创建 Service

首先创建 Service 层：

*src/main/java/com/nofirst/spring/tdd/zhihu/startup/service/QuestionService.java*

```java
package com.nofirst.spring.tdd.zhihu.startup.service;

import com.nofirst.spring.tdd.zhihu.startup.model.domain.Question;
import java.util.List;

public interface QuestionService {
    
    /**
     * 获取所有问题
     */
    List<Question> getAllQuestions();
}
```

*src/main/java/com/nofirst/spring/tdd/zhihu/startup/service/impl/QuestionServiceImpl.java*

```java
package com.nofirst.spring.tdd.zhihu.startup.service.impl;

import com.nofirst.spring.tdd.zhihu.startup.mapper.QuestionMapper;
import com.nofirst.spring.tdd.zhihu.startup.model.domain.Question;
import com.nofirst.spring.tdd.zhihu.startup.model.domain.QuestionExample;
import com.nofirst.spring.tdd.zhihu.startup.service.QuestionService;
import org.springframework.stereotype.Service;

@Service
public class QuestionServiceImpl implements QuestionService {

    private final QuestionMapper questionMapper;

    public QuestionServiceImpl(QuestionMapper questionMapper) {
        this.questionMapper = questionMapper;
    }

    @Override
    public List<Question> getAllQuestions() {
        QuestionExample example = new QuestionExample();
        return questionMapper.selectByExample(example);
    }
}
```

### 4.2 更新 Controller

更新 Controller 调用 Service：

```java
package com.nofirst.spring.tdd.zhihu.startup.controller;

import com.nofirst.spring.tdd.zhihu.startup.common.CommonResult;
import com.nofirst.spring.tdd.zhihu.startup.model.domain.Question;
import com.nofirst.spring.tdd.zhihu.startup.service.QuestionService;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

import java.util.List;

@RestController
public class QuestionController {

    private final QuestionService questionService;

    public QuestionController(QuestionService questionService) {
        this.questionService = questionService;
    }

    /**
     * 获取问题列表
     */
    @GetMapping("/questions")
    public CommonResult<List<Question>> index() {
        List<Question> questions = questionService.getAllQuestions();
        return CommonResult.success(questions);
    }
}
```

### 4.3 再次运行测试


测试应该通过！

## 六、测试命名规范

### 两种命名方式对比

| 方式 | 示例 | 特点 |
|------|------|------|
| **test 开头 + 驼峰** | `testUserCanViewQuestions()` | 传统方式，较冗长 |
| **下划线风格** | `user_can_view_questions()` | 可读性更好，推荐 |

### 推荐使用下划线风格

本教程所有测试方法均采用下划线风格：

- ✅ 可读性更佳，像一句完整的描述
- ✅ 清晰表达测试意图
- ✅ 符合行为驱动开发（BDD）理念

### 命名模板

```java
@Test
void [角色]_[动作]_[预期结果]() { }

@Test
void user_can_view_questions() { }

@Test
void guest_cannot_create_question() { }

@Test
void signed_in_user_can_answer_question() { }
```

## 八、总结

### 8.1 本节学习要点

| 要点 | 说明 |
|------|------|
| @BeforeEach | 在每个测试前执行，用于准备测试数据 |
| JSON 断言 | 使用 jsonPath 验证返回数据 |
| Service 层 | 分离业务逻辑，便于测试和维护 |
| 依赖注入 | 使用构造函数注入 Service |
| 测试命名 | 使用下划线风格提高可读性 |

### 8.2 测试最佳实践

- ✅ 每个测试应该独立
- ✅ 测试前清理数据
- ✅ 使用描述性的测试名称
- ✅ 验证完整的响应（状态码 + 数据）
- ✅ 测试边界情况（如空列表）

## 附录：常用 JsonPath 断言

```java
// 验证状态码
.andExpect(jsonPath("$.code").value(200))

// 验证消息
.andExpect(jsonPath("$.message").value("操作成功"))

// 验证数组
.andExpect(jsonPath("$.data").isArray())
.andExpect(jsonPath("$.data", hasSize(2)))

// 验证数组元素
.andExpect(jsonPath("$.data[0].title").value("如何学习 Spring Boot？"))
.andExpect(jsonPath("$.data[0].content").value("求指导..."))

// 验证字段存在
.andExpect(jsonPath("$.data").exists())
.andExpect(jsonPath("$.data").doesNotExist())

// 验证字符串
.andExpect(jsonPath("$.data.title").value("标题"))

// 验证数字
.andExpect(jsonPath("$.data.id").value(1))

// 验证布尔值
.andExpect(jsonPath("$.data.published").value(true))
```
