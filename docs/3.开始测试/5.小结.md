## 本章学习要点

### 测试框架前置知识

我们学习了以下测试工具和框架：

| 工具 | 用途 | 关键知识点 |
|------|------|-----------|
| **JUnit 5** | 测试框架 | `@Test`, `@BeforeEach`, `@BeforeAll`, `@TestInstance` |
| **AssertJ** | 断言库 | Fluent 风格断言，`assertThat()` |
| **Mockito** | Mock 框架 | `@Mock`, `@InjectMocks`, `when()`, `verify()` |
| **MockMvc** | Web 测试 | 模拟 HTTP 请求，`perform()`, `andExpect()` |
| **Testcontainers** | 容器化测试 | Docker 容器，`@Container`, 容器复用 |
| **Spring Boot Test** | Spring 测试 | `@SpringBootTest`, `@AutoConfigureMockMvc` |

### 项目脚手架

我们了解了项目脚手架的结构和配置：

- ✅ Maven 依赖配置
- ✅ Flyway 数据库迁移
- ✅ MyBatis Generator 代码生成
- ✅ 测试基类 `BaseContainerTest`

### TDD 开发流程

我们实践了完整的 TDD 循环：

```
┌─────────────────────────────────────────────────────────┐
│                   TDD 开发循环                          │
│                                                         │
│    ┌─────────┐     ┌─────────┐     ┌─────────┐        │
│    │  编写   │     │  运行   │     │  重构   │        │
│    │  测试   │ ──→ │  测试   │ ──→ │  代码   │        │
│    │ (失败)  │     │ (通过)  │     │         │        │
│    └─────────┘     └─────────┘     └─────────┘        │
│         ↑              │                              │
│         │              │                              │
│         └──────────────┘                              │
│              编写最少代码                              │
│                                                         │
└─────────────────────────────────────────────────────────┘
```
