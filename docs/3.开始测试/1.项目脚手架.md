# 创建项目脚手架

为了让你快速进入 TDD 实战，我们提供了一个基础的项目脚手架。本章将介绍如何获取和使用这个脚手架项目。

---

## 一、获取项目脚手架

由于篇幅限制，本文档不会介绍如何从零创建 Spring Boot 工程，而是提供一个包含基础配置和依赖的脚手架项目。

**项目地址：** [spring-tdd-zhihu-startup](https://github.com/qianhuihuiji/spring-tdd-zhihu-startup)

> 💡 **说明**：此脚手架项目不包含具体业务逻辑，仅包含：
> - 项目所需的 Maven 依赖
> - 常用公共类配置
> - 数据库迁移脚本
> - 测试基类
> - MyBatis Generator 配置

### 3.2 Flyway 插件

开发环境为了保持数据库结构的一致性，我们引入 `flyway` 插件进行数据库版本管理：

```xml
<build>
    <plugins>
        <plugin>
            <groupId>org.flywaydb</groupId>
            <artifactId>flyway-maven-plugin</artifactId>
            <version>10.0.0</version>
            <configuration>
                <url>jdbc:mysql://localhost:3306/zhihu</url>
                <user>root</user>
                <password>root</password>
            </configuration>
        </plugin>
    </plugins>
</build>
```

> **Flyway 说明**：Flyway 是一个开源的数据库版本控制工具，遵循「约定大于配置」原则。主要提供 migrate、clean、info、validate、baseline、repair 等命令，支持 SQL 和 Java 方式，并提供 Maven、Gradle 等插件支持。

## 四、数据库配置

### 4.1 应用配置

在 `src/main/resources/application.yaml` 中配置数据库连接：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/zhihu?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai
    username: root
    password: root
    driver-class-name: com.mysql.cj.jdbc.Driver
  
  flyway:
    enabled: true
    locations: classpath:db/migration
    baseline-on-migrate: true

mybatis:
  mapper-locations: classpath:mapper/*.xml
  type-aliases-package: com.nofirst.spring.tdd.zhihu.startup.model
```

### 4.2 创建数据库

在 MySQL 中创建数据库：

```sql
CREATE DATABASE zhihu CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

## 五、数据库迁移

### 5.1 运行 Flyway 迁移

脚手架项目内置了一份 `user` 表的建表语句：

*src/main/resources/db/migration/V2024010101__create_table_user.sql*

```sql
CREATE TABLE `user` (
    `id` int unsigned NOT NULL AUTO_INCREMENT,
    `name` varchar(50) NOT NULL,
    `email` varchar(100) NOT NULL,
    `password` varchar(100) NOT NULL,
    `avatar` varchar(255) DEFAULT NULL,
    `created_at` timestamp NULL DEFAULT NULL,
    `updated_at` timestamp NULL DEFAULT NULL,
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_email` (`email`)
) ENGINE=InnoDB AUTO_INCREMENT=1 DEFAULT CHARSET=utf8mb4;
```

运行 Maven 的 Flyway 插件命令执行迁移：

```bash
mvn flyway:migrate
```

执行成功后，数据库中会创建 `user` 表和 `flyway_schema_history` 表（用于记录迁移历史）。

### 5.2 Flyway 常用命令

| 命令 | 说明 |
|------|------|
| `mvn flyway:migrate` | 执行数据库迁移 |
| `mvn flyway:clean` | 清理数据库（删除所有表） |
| `mvn flyway:info` | 查看迁移状态 |
| `mvn flyway:validate` | 验证迁移脚本 |
| `mvn flyway:baseline` | 设置基准线 |

## 六、MyBatis Generator

我们使用 MyBatis 作为 ORM 框架，并配置了 MyBatis Generator 自动生成数据库映射代码。

### 6.1 配置文件

*src/main/resources/generatorConfig.xml*

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE generatorConfiguration PUBLIC "-//mybatis.org//DTD MyBatis Generator Configuration 1.0//EN" "http://mybatis.org/dtd/mybatis-generator-config_1_0.dtd">
<generatorConfiguration>
    <context id="context" targetRuntime="MyBatis3">
        <property name="javaFileEncoding" value="UTF-8"/>
        
        <!-- 数据库连接配置 -->
        <jdbcConnection driverClass="com.mysql.cj.jdbc.Driver"
                        connectionURL="jdbc:mysql://localhost:3306/zhihu"
                        userId="root"
                        password="root"/>
        
        <!-- 生成模型类 -->
        <javaModelGenerator targetPackage="com.nofirst.spring.tdd.zhihu.startup.model.domain"
                           targetProject="src/main/java"/>
        
        <!-- 生成 XML 映射文件 -->
        <sqlMapGenerator targetPackage="mapper"
                        targetProject="src/main/resources"/>
        
        <!-- 生成 Mapper 接口 -->
        <javaClientGenerator type="XMLMAPPER"
                            targetPackage="com.nofirst.spring.tdd.zhihu.startup.mapper"
                            targetProject="src/main/java"/>
        
        <!-- 配置要生成的表 -->
        <table tableName="user" domainObjectName="User">
            <generatedKey column="id" sqlStatement="JDBC" identity="true"/>
        </table>
    </context>
</generatorConfiguration>
```

### 6.2 生成代码

运行`Generator#main()`方法生成代码，生成后会自动创建以下文件：

```
src/main/java
└── com.nofirst.spring.tdd.zhihu.startup
    ├── model/domain
    │   ├── User.java           # 实体类
    │   └── UserExample.java    # 查询条件类
    └── mapper
        └── UserMapper.java     # Mapper 接口

src/main/resources
└── mapper
    └── UserMapper.xml          # SQL 映射文件
```

### 6.3 添加新表时的操作

当需要添加新表时：

1. 创建新的 Flyway 迁移脚本（如 `V2024010201__create_table_question.sql`）
2. 运行 `mvn flyway:migrate` 执行迁移
3. 修改 `generatorConfig.xml`，添加新表配置
4. 运行 `mvn mybatis-generator:generate` 生成代码

## 七、测试基类

为了简化集成测试，我们创建了 `BaseContainerTest` 测试基类。

### 7.1 基类代码

*src/test/java/com/nofirst/spring/tdd/zhihu/startup/BaseContainerTest.java*

```java
@Testcontainers
@SpringBootTest
@AutoConfigureMockMvc
public abstract class BaseContainerTest {

    @Container
    static MySQLContainer<?> mysql = new MySQLContainer<>("mysql:8.0")
        .withDatabaseName("test_db")
        .withUsername("test")
        .withPassword("test")
        .withReuse(true); // 复用容器

    @DynamicPropertySource
    static void configureTestProperties(DynamicPropertyRegistry registry) {
        registry.add("spring.datasource.url", mysql::getJdbcUrl);
        registry.add("spring.datasource.username", mysql::getUsername);
        registry.add("spring.datasource.password", mysql::getPassword);
    }
}
```

### 7.2 基类说明

| 注解/特性 | 说明 |
|----------|------|
| `@Testcontainers` | 启用 Testcontainers 支持 |
| `@SpringBootTest` | 加载完整的 Spring 应用上下文 |
| `@AutoConfigureMockMvc` | 自动配置 MockMvc |
| `@Container` | 标记容器实例 |
| `@DynamicPropertySource` | 动态配置测试属性 |
| `withReuse(true)` | 复用运行中的容器 |

### 7.3 使用方式

所有集成测试只需继承此基类：

```java
class ViewQuestionsTest extends BaseContainerTest {

    @Autowired
    private MockMvc mockMvc;

    @Test
    void shouldReturnQuestions() throws Exception {
        mockMvc.perform(get("/questions"))
            .andExpect(status().isOk());
    }
}
```

## 九、常见问题

### Q: 为什么测试运行时 Docker 报错？

**A:** 确保 Docker Desktop 已启动，并且当前用户有权限访问 Docker 守护进程。

### Q: Flyway 迁移失败怎么办？

**A:** 检查数据库连接配置是否正确，数据库是否已创建。

### Q: 如何添加新的数据表？

**A:** 
1. 创建新的 Flyway 迁移脚本
2. 运行 `mvn flyway:migrate`
3. 修改 `generatorConfig.xml` 添加新表
4. 运行 `mvn mybatis-generator:generate`

### Q: 可以修改包名吗？

**A:** 可以，但需要同步修改：
- `pom.xml` 中的相关配置
- `generatorConfig.xml` 中的包名
- `application.yaml` 中的 MyBatis 配置
