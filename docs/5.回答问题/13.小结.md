## 一、本章学习要点

### 1.1 回答问题

我们学习了如何实现回答功能：

| 知识点 | 说明 |
|--------|------|
| 集成测试 | 使用 MockMvc 测试回答接口 |
| 数据模型 | 创建 `answer` 表和 ORM 映射 |
| 工厂模式 | 使用 `AnswerFactory` 创建测试数据 |
| 单元测试 | 使用 Mockito 测试 Service 层逻辑 |
| 自定义 Matcher | 验证复杂对象的参数匹配 |

### 1.2 问题的发布属性

我们学习了如何添加发布状态控制：

| 知识点 | 说明 |
|--------|------|
| 数据库迁移 | 使用 Flyway 添加 `published_at` 字段 |
| 状态验证 | 只能查看和回答已发布的问题 |
| 异常处理 | 未发布问题抛出 `QuestionNotPublishedException` |

### 1.3 代码重构

我们学习了如何优化代码：

| 知识点 | 说明 |
|--------|------|
| 重构原则 | 不改变行为，测试保护 |
| 工厂方法 | 添加 `createPublishedQuestion()` 和 `createUnpublishedQuestion()` |
| 意图命名 | 方法名清晰表达目的 |

### 1.4 表单验证

我们学习了如何验证用户输入：

| 知识点 | 说明 |
|--------|------|
| Validation 框架 | 使用 `@Validated` 和 `@NotBlank` |
| 安全原则 | 永远不要相信用户的输入 |
| 用户认证 | 使用 `@AuthenticationPrincipal` 获取当前用户 |

### 1.5 权限控制

我们学习了如何控制访问权限：

| 知识点 | 说明 |
|--------|------|
| Spring Security | 启用安全认证 |
| 未登录测试 | 测试未登录用户返回 401 |
| 模拟用户 | 使用 `@WithUserDetails` 模拟登录用户 |

### 1.6 最佳答案

我们学习了如何实现最佳答案功能：

| 知识点 | 说明 |
|--------|------|
| 数据库设计 | 添加 `best_answer_id` 字段 |
| 扩展 Mapper | 使用 `QuestionMapperExt` 添加自定义 SQL |
| Policy 模式 | 使用独立的 Policy 类控制权限 |
| @PreAuthorize | Spring Security 权限注解 |

### 1.7 删除答案

我们学习了如何实现删除功能：

| 知识点 | 说明 |
|--------|------|
| RESTful 风格 | 使用 `@DeleteMapping` 定义删除接口 |
| 权限策略 | 使用 `AnswerPolicy` 控制只有作者可以删除 |
| 测试覆盖 | 未登录、非作者、作者三种场景 |

### 1.8 答案列表

我们学习了如何显示答案列表：

| 知识点 | 说明 |
|--------|------|
| 关联查询 | 查看问题时同时返回答案列表 |
| PageHelper | 使用 PageHelper 实现分页 |
| PageInfo | 返回分页对象包含总数和列表 |

### 1.9 整理测试目录

我们学习了如何组织测试文件：

| 知识点 | 说明 |
|--------|------|

## 四、技术要点

### 4.1 TDD 流程

```
┌─────────────────────────────────────────────────────────┐
│                  第五章 TDD 流程                         │
│                                                         │
│  1. 编写集成测试 ──────→ 2. 运行测试（失败）           │
│                               ↓                         │
│  4. 编写单元测试 ←──────── 3. 创建数据模型              │
│       ↓                       ↓                         │
│  7. 运行测试（通过） ←──── 5. 实现 Service 层           │
│       ↓                                                 │
│  8. 完善 Controller ──────→ 9. 运行全部测试            │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 4.2 权限控制模式

```java
// Policy 模式
@Component
public class AnswerPolicy {
    public boolean canDelete(Integer answerId, AccountUser accountUser) {
        // 验证权限逻辑
        return true; // 或 false
    }
}

// Controller 中使用
@DeleteMapping("/answers/{answerId}")
@PreAuthorize("@answerPolicy.canDelete(#answerId, #accountUser)")
public CommonResult<String> destroy(...) {
    // ...
}
```

### 4.3 分页查询模式

```java
// Service 层
public PageInfo<Answer> answers(Integer questionId, int pageIndex, int pageSize) {
    PageHelper.startPage(pageIndex, pageSize);
    List<Answer> answers = answerMapperExt.selectByQuestionId(questionId);
    return new PageInfo<>(answers);
}
```

### 提交回答

```java
@PostMapping("/questions/{questionId}/answers")
public CommonResult<String> store(@PathVariable Integer questionId,
                                  @RequestBody @Validated AnswerDto answerDto,
                                  @AuthenticationPrincipal AccountUser accountUser) {
    answerService.store(questionId, answerDto, accountUser);
    return CommonResult.success("success");
}
```

### 标记最佳

```java
@PostMapping("/answers/{answerId}/best")
@PreAuthorize("@questionPolicy.canMarkAnswerAsBest(#answerId, #accountUser)")
public CommonResult<String> markAsBest(@PathVariable Integer answerId,
                                       @AuthenticationPrincipal AccountUser accountUser) {
    answerService.markAsBest(answerId);
    return CommonResult.success("ok");
}
```

### 删除回答

```java
@DeleteMapping("/answers/{answerId}")
@PreAuthorize("@answerPolicy.canDelete(#answerId, #accountUser)")
public CommonResult<String> destroy(@PathVariable Integer answerId,
                                    @AuthenticationPrincipal AccountUser accountUser) {
    answerService.destroy(answerId);
    return CommonResult.success("ok");
}
```
