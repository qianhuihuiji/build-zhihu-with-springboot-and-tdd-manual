## 单元测试

在模型中新增 `voteUp()` 方法之前，应该先做单元测试。所以新增单元测试：

*tests/Unit/AnswerTest.php*
```
.
.
.
    /** @test */
    public function can_vote_up_an_answer()
    {
        $this->signIn();

        $answer = create(Answer::class);

        $this->assertDatabaseMissing('votes', [
            'user_id' => auth()->id(),
            'voted_id' => $answer->id,
            'voted_type' => get_class($answer),
            'type' => 'vote_up',
        ]);

        $answer->voteUp(auth()->user());

        $this->assertDatabaseHas('votes', [
            'user_id' => auth()->id(),
            'voted_id' => $answer->id,
            'voted_type' => get_class($answer),
            'type' => 'vote_up',
        ]);
    }
}
```

运行测试：

```
$ phpunit --filter can_vote_up_an_answer

    public function voteUp($user)
    {
        $this->votes('vote_up')->create(['user_id' => $user->id, 'type' => 'vote_up']);
    }

    public function votes($type)
    {
        return $this->morphMany(Vote::class, 'voted')->whereType($type);
    }
}
```

到这里你肯定发现我们又添加了 `votes`方法，**那我们需要添加单元测试吗？**其实不必，因为我们已经为`voteUp`方法添加了单元测试，只要`voteUp`方法的单元测试通过，那么`votes`方法就是正常的。
