# 获取赞同数量

本节我们来获取一些跟赞同有关的数据：是否被赞同以及赞同的数量。

---

## 一、功能说明

### 1.1 查询投票数据

在问答系统中，用户和回答者都需要知道：

| 数据 | 说明 |
|------|------|
| 是否被赞同 | 当前用户是否赞同了该回答 |
| 赞同数量 | 该回答获得了多少赞同 |

### 1.2 开发目标

| 目标 | 说明 |
|------|------|
| 查询是否被赞同 | `isVotedUp()` 方法 |
| 查询赞同数量 | `upVotesCount()` 方法 |
| 单元测试 + 集成测试 | 两种测试覆盖 |


*src/main/java/com/nofirst/spring/tdd/zhihu/startup/service/impl/AnswerServiceImpl.java*

```java
@Override
public Boolean isVotedUp(Integer answerId) {
    VoteExample voteExample = new VoteExample();
    VoteExample.Criteria criteria = voteExample.createCriteria();
    criteria.andVotedIdEqualTo(answerId);
    criteria.andResourceTypeEqualTo(Answer.class.getSimpleName());
    criteria.andActionTypeEqualTo(VoteActionType.VOTE_UP.getCode());
    long count = voteMapper.countByExample(voteExample);
    return count > 0;
}
```

## 三、用户知道点赞数

### 3.1 添加测试用例

添加测试：

*src/test/java/com/nofirst/spring/tdd/zhihu/startup/integration/answers/UpVotesTest.java*

```java
@Test
@WithUserDetails(value = "John", userDetailsServiceBeanName = "customUserDetailsService")
void can_know_up_votes_count() throws Exception {
    long count = answerService.upVotesCount(1);
    assertThat(count).isEqualTo(0L);
    // given when
    this.mockMvc.perform(post("/answers/1/up-votes"));

    // when
```

| 步骤 | 说明 |

## 四、总结

### 4.1 本节学习要点

| 要点 | 说明 |
|------|------|
| 查询方法 | `isVotedUp()` 和 `upVotesCount()` |
| 测试策略 | 单元测试 + 集成测试双重覆盖 |
| Mock 使用 | 单元测试中使用 Mock 隔离依赖 |

### 4.2 投票查询方法

```java
// AnswerService 接口
public interface AnswerService {
    // 查询是否被赞同
    Boolean isVotedUp(Integer answerId);
    
    // 查询赞同数量
    long upVotesCount(Integer answerId);
}
```

### 4.3 使用场景

| 场景 | 使用的方法 |
|------|-----------|
| 显示回答列表 | `upVotesCount()` - 显示赞同数 |
| 高亮已赞同回答 | `isVotedUp()` - 标记用户已赞同 |
| 回答详情页 | 两者都用 - 显示数量和状态 |
