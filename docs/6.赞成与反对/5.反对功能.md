# 反对功能

本节我们来开发对答案的反对功能。

---

## 一、功能说明

### 1.1 反对功能

与赞同功能相对应，用户也可以对不满意的回答表示反对。反对功能的设计和实现与赞同功能类似。

### 1.2 开发目标

| 目标 | 说明 |
|------|------|
| 未登录用户不能反对 | 返回 401 未授权 |
| 登录用户可以反对 | 创建投票记录 |
| 使用同一张 vote 表 | 通过 `action_type` 区分赞同/反对 |

```java
@Test
@WithUserDetails(value = "John", userDetailsServiceBeanName = "customUserDetailsService")
void authenticated_user_can_vote_down() throws Exception {
    // given
    this.mockMvc.perform(post("/answers/1/down-votes"))
            .andDo(print())
            .andExpect(status().isOk())
            .andExpect(jsonPath("$.code").value(ResultCode.SUCCESS.getCode()));

    VoteExample voteExample = new VoteExample();
    VoteExample.Criteria criteria = voteExample.createCriteria();
    criteria.andVotedIdEqualTo(1);
    criteria.andResourceTypeEqualTo(Answer.class.getSimpleName());
    criteria.andActionTypeEqualTo(VoteActionType.VOTE_DOWN.getCode());
    List<Vote> votes = voteMapper.selectByExample(voteExample);

    assertThat(votes).size().isEqualTo(1);
}
```

| `given` | 发送 POST 请求到 `/answers/1/down-votes` |

## 五、实现 Service 层

### 5.1 创建 Service 接口

补充完整逻辑：

*src/main/java/com/nofirst/spring/tdd/zhihu/startup/service/AnswerVoteDownService.java*

```java
public interface AnswerVoteDownService {

    void store(Integer answerId, AccountUser accountUser);
}
```

### 5.2 实现 Service

*src/main/java/com/nofirst/spring/tdd/zhihu/startup/service/impl/AnswerVoteDownServiceImpl.java*

```java
@Service
@AllArgsConstructor
public class AnswerVoteDownServiceImpl implements AnswerVoteDownService {

    private VoteMapper voteMapper;

    @Override
    public void store(Integer answerId, AccountUser accountUser) {
        Vote vote = new Vote();
        vote.setUserId(accountUser.getUserId());
        vote.setVotedId(answerId);
        vote.setResourceType(Answer.class.getSimpleName());
        vote.setActionType(VoteActionType.VOTE_DOWN.getCode());
        Date now = new Date();
        vote.setCreatedAt(now);
        vote.setUpdatedAt(now);

        voteMapper.insert(vote);
    }
}
```

### 5.3 完善 Controller

*src/main/java/com/nofirst/spring/tdd/zhihu/startup/controller/AnswerDownVoteController.java*

```java
@RestController
@AllArgsConstructor
public class AnswerDownVoteController {

    private final AnswerVoteDownService answerVoteDownService;

    @PostMapping("/answers/{answerId}/down-votes")
    public CommonResult<String> store(@PathVariable Integer answerId, @AuthenticationPrincipal AccountUser accountUser) {
        answerVoteDownService.store(answerId, accountUser);
        return CommonResult.success("ok");
    }
}
```

## 六、总结

### 6.1 本节学习要点

| 要点 | 说明 |
|------|------|
| 反对功能 | 与赞同功能类似，使用不同的 `action_type` |
| 代码复用 | 使用同一张 vote 表，相同的 VoteMapper |
| 枚举区分 | 使用 `VoteActionType.VOTE_DOWN` 标识反对 |

### 6.2 赞同 vs 反对

| 对比项 | 赞同 | 反对 |
|--------|------|------|
| 接口路径 | `/up-votes` | `/down-votes` |
| Controller | `AnswerUpVoteController` | `AnswerDownVoteController` |
| Service | `AnswerVoteUpService` | `AnswerVoteDownService` |
| action_type | `vote_up` | `vote_down` |
| 数据表 | 同一张 `vote` 表 | 同一张 `vote` 表 |
