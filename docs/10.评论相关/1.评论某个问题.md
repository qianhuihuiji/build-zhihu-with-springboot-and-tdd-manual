## 重构代码

现在功能测试都已通过，是时候来做点重构了。就像前面说的那样，我们会将与数据库交互的逻辑放到模型文件里面。所以我们希望通过下面这样的代码来添加评论：

```
$comment = $question->comment(request('content'), auth()->user());
```

但是在此之前，让我们先来添加单元测试：

*tests/Unit/QuestionTest.php*
```
.

    public function can_comment_a_question()
    {
        $question = create(Question::class);

        $this->assertEquals(1, $question->refresh()->comments()->count());
    }
}
```
