# 小结

## 本章学习要点

### 用户动态

我们学习了如何实现用户动态记录功能：

| 知识点 | 说明 |
|--------|------|
| 事件机制 | 使用 Spring ApplicationEvent 记录活动 |
| 事件监听 | 使用 `@EventListener` 监听多个事件 |
| 活动记录 | 记录用户行为和关联对象 |

### 活跃用户

我们学习了如何计算活跃用户：

| 知识点 | 说明 |
|--------|------|
| Redis 缓存 | 使用 Redis 缓存活跃用户列表 |
| 积分计算 | 问题 4 分，回答 1 分 |
| 定时任务 | 使用 `@Scheduled` 每天计算 |
| Testcontainers | 使用 RedisContainer 进行测试 |

### 未读消息

我们学习了如何实现未读消息功能：

| 知识点 | 说明 |
|--------|------|
| 分页查询 | 使用 PageHelper 实现消息分页 |
| 权限控制 | 未登录用户返回 401 |
| 标记已读 | 查看后自动标记为已读 |
