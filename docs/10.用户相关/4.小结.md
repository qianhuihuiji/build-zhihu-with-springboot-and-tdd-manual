## 四、技术要点

### 4.1 TDD 流程

```
┌─────────────────────────────────────────────────────────┐
│                  第十章 TDD 流程                         │
│                                                         │
│  1. 编写集成测试 ──────→ 2. 运行测试（失败）           │
│                               ↓                         │
│  4. 编写单元测试 ←──────── 3. 创建数据模型              │
│       ↓                       ↓                         │
│  7. 运行测试（通过） ←──── 5. 实现 Service 层           │
│       ↓                                                 │
│  8. 完善 Controller ──────→ 9. 运行全部测试            │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 4.2 事件机制

```
┌─────────────────────────────────────────────────────────┐
│              用户动态事件流程                            │
│                                                         │
│  发布问题 ──────→ 触发 PublishQuestionEvent           │
│                              ↓                          │
│              ┌───────────────────────┐                 │
│              │   事件监听器           │                 │
│              │  - 记录活动            │                 │
│              │  - 发送通知            │                 │
│              └───────────────────────┘                 │
│                                                         │
│  创建回答 ──────→ 触发 PostAnswerEvent               │
│                              ↓                          │
│              ┌───────────────────────┐                 │
│              │   事件监听器           │                 │
│              │  - 记录活动            │                 │
│              │  - 发送通知            │                 │
│              └───────────────────────┘                 │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 4.3 活跃用户算法

```
┌─────────────────────────────────────────────────────────┐
│                  活跃用户计算流程                        │
│                                                         │
│  1. 查询最近 7 天的问题 → 用户 ID + 数量 × 4 分          │
│                              ↓                          │
│  2. 查询最近 7 天的回答 → 用户 ID + 数量 × 1 分          │
│                              ↓                          │
│  3. 合并分数 → 按总分倒序排列                           │
│                              ↓                          │
│  4. 取前 6 名 → 缓存到 Redis（1 小时过期）              │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 4.4 Redis 缓存

// 缓存配置

public static Integer CACHE_EXPIRE_IN_SECONDS = 60 * 60; // 1 小时

public void recordActivity(PublishQuestionEvent event) {
    Question question = event.getQuestion();
    Activity activity = new Activity();
    activity.setUserId(question.getUserId());
    activity.setType("published_question");
    activity.setSubjectId(question.getId());
    activity.setSubjectType(question.getClass().getSimpleName());
    Date now = new Date();
    activity.setCreatedAt(now);
    activity.setUpdatedAt(now);
    activityMapper.insert(activity);
}

### Redis 缓存

```java
// 写入缓存
public void cacheActiveUsers(List<UserVo> users) {
    this.jsonRedisTemplate.opsForValue()
        .set(CACHE_KEY, users, Duration.ofSeconds(CACHE_EXPIRE_IN_SECONDS));
}

// 读取缓存
public List<UserVo> getActiveUsers() {
    List<UserVo> users = (List<UserVo>) jsonRedisTemplate.opsForValue().get(CACHE_KEY);
    if (CollectionUtils.isEmpty(users)) {
        return calculateActiveUsers();
    }
    return users;
}
```
