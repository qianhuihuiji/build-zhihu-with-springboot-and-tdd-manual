## 一、功能说明

### 1.1 表单验证规则

接下来我们来添加一些表单验证的规则：

| 字段 | 规则 | 说明 |
|------|------|------|
| `title` | 必填 | 标题不能为空 |
| `content` | 必填 | 内容不能为空 |
| `category_id` | 必填且有效 | 分类必须存在 |

### 1.2 开发目标

| 目标 | 说明 |
|------|------|
| 验证 title 必填 | 使用 `@NotBlank` 注解 |
| 验证 content 必填 | 使用 `@NotBlank` 注解 |
| 验证 category_id 必填 | 使用 `@NotNull` 注解 |
| 验证 category_id 有效 | 使用自定义 `Validator` |

## 三、添加验证规则

### 3.1 添加 @NotBlank 注解

接下来我们来添加验证规则：

*src/main/java/com/nofirst/spring/tdd/zhihu/startup/model/dto/QuestionDto.java*

```java
@Data
public class QuestionDto {

    @NotBlank(message = "标题不能为空")
    private String title;

    private String content;

    private Integer categoryId;
}
```

### 3.2 使验证生效

使规则生效：

```java
@PostMapping("/questions")
public CommonResult<String> store(@RequestBody @Validated QuestionDto dto, @AuthenticationPrincipal AccountUser accountUser) {
    questionService.store(dto, accountUser);
    return CommonResult.success("ok");
}
```

## 七、自定义 Validator

### 7.1 创建 Validator

接下来我们自定义一个 `Validator` 来进行此类的校验逻辑：

> 💡 **提示**：还记得之前的 `AnswerPolicy` 吗？现在我们有两种不同的前置校验方式了。

*src/main/java/com/nofirst/spring/tdd/zhihu/startup/validator/ValidCategoryValidator.java*

```java
@Component
@AllArgsConstructor
public class ValidCategoryValidator implements ConstraintValidator<ValidCategory, QuestionDto> {

    private CategoryMapper categoryMapper;

    @Override
    public boolean isValid(QuestionDto value, ConstraintValidatorContext context) {
        Category category = categoryMapper.selectByPrimaryKey(value.getCategoryId());

        if (Objects.isNull(category)) {
            // 这里可以设置 ValidCategory 的 message，可以应对复杂的消息提醒
            context.disableDefaultConstraintViolation();
            context.buildConstraintViolationWithTemplate("问题分类不存在")
                    .addConstraintViolation();

            return false;
        }

        return true;
    }
}
```

### 7.2 创建注解

定义一个注解：

*src/main/java/com/nofirst/spring/tdd/zhihu/startup/validator/ValidCategory.java*

```java
@Constraint(validatedBy = {ValidCategoryValidator.class})
@Target({METHOD, FIELD, ANNOTATION_TYPE, CONSTRUCTOR, PARAMETER})
@Retention(RUNTIME)
public @interface ValidCategory {

    /**
     * 不合法时 抛出异常信息
     *
     * @return the string
     */
    String message() default "问题分类不存在";


    Class<?>[] groups() default {};


    Class<? extends Payload>[] payload() default {};
}
```

### 7.3 应用注解

应用该注解：

*src/main/java/com/nofirst/spring/tdd/zhihu/startup/controller/QuestionController.java*

```java
@Validated // 注解从从方法内移到了类上，如果不这样做@ValidCategory 不会生效，研究一下这是为什么呢？
public class QuestionController {
    .
    .
    .
    @PostMapping("/questions")
    public CommonResult<String> store(@RequestBody @ValidCategory QuestionDto dto, @AuthenticationPrincipal AccountUser accountUser) {
        questionService.store(dto, accountUser);
        return CommonResult.success("ok");
    }
}
```

```java
public class QuestionFactory {

    public static Question createPublishedQuestion() {
        Date lastWeek = DateUtils.addWeeks(new Date(), -1);
        Date now = new Date();

        Question question = new Question();
        question.setUserId(1);
        question.setTitle("this is a question");
        question.setContent("this is content");
        question.setCreatedAt(now);
        question.setUpdatedAt(now);
        question.setPublishedAt(lastWeek);
        question.setCategoryId(1);

        return question;
    }

    public static Question createUnpublishedQuestion() {
        Date now = new Date();

        Question question = new Question();
        question.setUserId(1);
        question.setTitle("this is a question");
        question.setContent("this is content");
        question.setCreatedAt(now);
        question.setUpdatedAt(now);
        question.setPublishedAt(null);
        question.setCategoryId(1);

        return question;
    }


    public static QuestionDto createQuestionDto() {
        QuestionDto questionDto = new QuestionDto();
        questionDto.setTitle("this is a new question");
        questionDto.setContent("question content");
        questionDto.setCategoryId(1);

        return questionDto;
    }
}
```

## 十、总结

### 10.1 本节学习要点

| 要点 | 说明 |
|------|------|
| 表单验证 | 使用 `@Validated` 和验证注解 |
| 内置注解 | `@NotBlank`、`@NotNull` |
| 自定义 Validator | 实现 `ConstraintValidator` 接口 |
| 自定义注解 | 使用 `@Constraint` 元注解 |

### 10.2 验证规则汇总

| 字段 | 注解 | 消息 |
|------|------|------|
| `title` | `@NotBlank` | "标题不能为空" |
| `content` | `@NotBlank` | "内容不能为空" |
| `categoryId` | `@NotNull` | "问题分类不能为空" |
| `categoryId` | `@ValidCategory` | "问题分类不存在" |

## 附录：常用验证注解

```java
// 字符串验证
@NotBlank(message = "不能为空")     // 非 null 且非空
@NotNull(message = "不能为 null")    // 非 null
@Size(min = 1, max = 100)          // 长度范围
@Email(message = "邮箱格式不正确")   // 邮箱格式

// 数值验证
@Min(value = 0, message = "最小值为 0")      // 最小值
@Max(value = 100, message = "最大值为 100")  // 最大值
@DecimalMin("0.01")  // 最小值（小数）
@DecimalMax("99.99") // 最大值（小数）

// 其他
@Pattern(regexp = "...", message = "格式不正确")  // 正则匹配
@Future(message = "必须是未来时间")  // 未来时间
@Past(message = "必须是过去时间")   // 过去时间
```
