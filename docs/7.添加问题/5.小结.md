## 本章学习要点

### 创建问题

我们学习了如何实现创建问题功能：

| 知识点 | 说明 |
|--------|------|
| 权限控制 | 未登录用户返回 401 |
| 分类功能 | 支持问题分类，添加 category 表 |
| 数据库迁移 | 使用 Flyway 管理表结构变更 |
| DTO 设计 | 使用 QuestionDto 接收请求参数 |

### 表单验证

我们学习了如何添加表单验证：

| 知识点 | 说明 |
|--------|------|
| 内置注解 | `@NotBlank`、`@NotNull` |
| 自定义 Validator | 实现 `ConstraintValidator` 接口 |
| 自定义注解 | 使用 `@Constraint` 元注解 |
| 验证规则 | title、content、categoryId 必填 |

### 发布问题

我们学习了如何实现发布问题功能：

| 知识点 | 说明 |
|--------|------|
| 发布功能 | 设置 `published_at` 时间戳 |
| 权限控制 | 使用 `@PreAuthorize` 和 Policy |
| 扩展 Mapper | 使用 `QuestionMapperExt` 添加自定义 SQL |
| 测试覆盖 | 未登录、非作者、作者三种场景 |

### 邀请某人

我们学习了如何实现@用户功能：

| 知识点 | 说明 |
|--------|------|
| 事件机制 | 使用 Spring ApplicationEvent |
| 事件发布者 | 使用 `ApplicationEventPublisher` |
| 事件监听器 | 使用 `@EventListener` 注解 |
| 正则表达式 | 使用正则提取@的用户名 |
