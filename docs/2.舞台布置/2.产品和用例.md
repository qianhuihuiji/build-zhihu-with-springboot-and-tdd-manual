# 产品和用例

在开始编写代码之前，我们需要先了解要开发的项目。本章将从产品需求和用例的角度分析 SpringZhihu 系统，帮助你对项目有个整体概念。

> 💡 **说明**：SpringZhihu 是一个仿知乎的问答系统，但本项目的核心目标不是构建产品，而是**通过实战教授 TDD 和测试技能**。

---

## 一、项目概述

**SpringZhihu** 是一套允许用户**提问题、写回答、做评论**的问答系统。我们将以该项目为基础，学习如何使用测试工具（如 JUnit 5、Spring Test、Testcontainers 等）来编写单元测试和集成测试。

---

## 二、系统角色

SpringZhihu 中有两种角色：

| 角色 | 说明 | 权限 |
|------|------|------|
| **游客** | 未登录的访客 | 仅可查看公开内容 |
| **用户** | 已注册的登录用户 | 可参与互动（提问、回答、评论等） |

---

## 三、信息结构（数据模型）

系统的主要数据模型如下：

| 模型 | 说明 | 对应表名 |
|------|------|---------|
| User | 用户 | `user` |
| Question | 问题 | `question` |
| Answer | 回答 | `answer` |
| Comment | 评论 | `comment` |
| Activity | 用户动态 | `activity` |
| Vote | 投票（赞同/反对） | `vote` |

> 💡 **提示**：数据库表结构将在后续章节通过 Flyway 迁移脚本逐步创建。

---

## 四、核心功能模块

根据教程章节，SpringZhihu 包含以下功能模块：

```
SpringZhihu
├── 问题模块       # 创建、查看、编辑、删除问题
├── 回答模块       # 创建、查看、删除回答，设置最佳答案
├── 评论模块       # 对问题/回答进行评论
├── 投票模块       # 赞同/反对问题和回答
├── 互动模块       # 关注问题、推荐、举报、筛选
└── 用户模块       # 用户动态、消息通知
```

## 五、用例详解

### 5.1 游客（未登录用户）

游客可以执行以下操作：

| 功能 | 说明 |
|------|------|
| 查看问题列表 | 浏览所有已发布的问题 |
| 查看问题详情 | 查看单个问题及其回答列表 |
| 查看评论 | 查看问题和回答的评论 |

> ⚠️ **注意**：游客**不能**进行任何写操作（创建、编辑、删除、投票、评论等）。

---

### 5.2 用户（已登录用户）

#### 5.2.1 对问题的操作

| 功能 | 说明 | 对应章节 |
|------|------|---------|
| 创建问题 | 发布新问题 | 第 7 章 |
| 查看问题 | 查看问题详情 | 第 4 章 |
| 编辑问题 | 修改自己创建的问题 | - |
| 删除问题 | 删除自己创建的问题 | - |
| 推荐/不推荐 | 对问题进行投票 | 第 6 章 |
| 关注问题 | 关注感兴趣的问题 | 第 8 章 |
| 回答问题 | 对问题进行回答 | 第 5 章 |
| 评论问题 | 对问题发表评论 | 第 9 章 |

#### 5.2.2 对回答的操作

| 功能 | 说明 | 对应章节 |
|------|------|---------|
| 创建回答 | 对问题进行回答 | 第 5 章 |
| 查看回答 | 查看回答详情 | 第 4 章 |
| 删除回答 | 删除自己的回答 | 第 5 章 |
| 设置最佳答案 | 提问者标记最佳答案 | 第 5 章 |
| 赞同/反对 | 对回答进行投票 | 第 6 章 |
| 评论回答 | 对回答发表评论 | 第 9 章 |

#### 5.2.3 对评论的操作

| 功能 | 说明 | 对应章节 |
|------|------|---------|
| 创建评论 | 对问题/回答进行评论 | 第 9 章 |
| 查看评论 | 查看问题/回答的评论列表 | 第 9 章 |
| 赞同/反对评论 | 对评论进行投票 | 第 9 章 |

#### 5.2.4 对账户的操作

| 功能 | 说明 | 对应章节 |
|------|------|---------|
| 邮箱验证 | 通过邮箱确认账户真实性 | 第 10 章 |
| 上传头像 | 上传用户头像图片 | 第 10 章 |
| 查看动态 | 查看用户的发布记录 | 第 10 章 |
| 查看消息 | 查看未读消息通知 | 第 10 章 |

## 七、测试学习目标

通过 SpringZhihu 项目，你将学习以下测试技能：

| 测试类型 | 学习内容 | 对应章节 |
|---------|---------|---------|
| **单元测试** | 测试 Service、Policy 层逻辑 | 第 5 章 |
| **集成测试** | 测试 Controller 层完整流程 | 第 3-10 章 |
| **数据库测试** | 使用 Testcontainers 创建测试数据库 | 第 3 章 |
| **表单验证测试** | 测试请求参数的有效性 | 第 5、7 章 |
| **权限测试** | 测试 Spring Security 认证和授权 | 第 5 章 |
| **异常测试** | 测试业务异常处理 | 第 4 章 |
| **事件测试** | 测试领域事件和监听器 | 第 10 章 |

## 八、CRUD 操作映射

角色与信息之间的互动可归纳为以下四种基本操作：

| 操作 | 英文 | 说明 | 示例 |
|------|------|------|------|
| 创建 | Create | 新增数据 | 创建问题、发布回答 |
| 查看 | Read | 查询数据 | 查看问题列表、查看详情 |
| 编辑 | Update | 修改数据 | 编辑问题内容 |
| 删除 | Delete | 删除数据 | 删除回答、删除评论 |

## 九、项目范围说明

### 本项目包含的功能

- ✅ 问题管理（创建、查看、编辑、删除）
- ✅ 回答管理（创建、查看、删除、设置最佳）
- ✅ 评论功能（对问题/回答进行评论）
- ✅ 投票功能（赞同/反对问题和回答）
- ✅ 互动功能（关注、推荐、举报、筛选）
- ✅ 用户功能（动态、消息、头像、邮箱验证）

### 本项目不包含的功能

以下功能**不在本教程范围内**，但你可以作为扩展练习自行实现：

- ❌ 完整的用户注册/登录系统（使用预设测试用户）
- ❌ 搜索功能（使用简单的筛选代替）
- ❌ 标签/话题系统
- ❌ 私信功能
