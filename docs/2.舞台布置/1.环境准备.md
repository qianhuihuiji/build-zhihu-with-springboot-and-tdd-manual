# 环境准备

本文档将详细列出本项目所需的环境依赖，并提供安装和配置指南。

> 💡 **提示**：本教程不涉及详细的环境搭建步骤，仅列出必要的环境依赖列表和配置说明。如需详细的安装教程，请参考各软件的官方文档。

---

## 必需环境

### 1. JDK 17+

本项目基于 Spring Boot 3.x 开发，需要 **JDK 17** 或更高版本（推荐使用 LTS 版本）。

**安装步骤：**

1. 访问 [Oracle JDK 下载页面](https://www.oracle.com/java/technologies/downloads/) 或 [OpenJDK](https://openjdk.org/)
2. 下载对应操作系统的 JDK 17 安装包
3. 安装完成后，配置 `JAVA_HOME` 环境变量

**验证安装：**

```bash
java -version
```

预期输出：

```
java version "17.0.x" ...
```

**配置 JAVA_HOME（Windows）：**

```
JAVA_HOME = C:\Program Files\Java\jdk-17
Path = %JAVA_HOME%\bin
```

### 3. Maven 3.8+

Java 项目构建和依赖管理工具。IntelliJ IDEA 自带 Maven，也可单独安装。

**下载链接：**

- [Maven 官网](https://maven.apache.org/download.cgi)

**验证安装：**

```bash
mvn -version
```

预期输出：

```
Apache Maven 3.8.x ...
```

**配置 Maven 镜像（推荐）：**

编辑 `~/.m2/settings.xml`（Windows: `C:\Users\你的用户名\.m2\settings.xml`），配置阿里云镜像加速下载：

```xml
<settings>
  <mirrors>
    <mirror>
      <id>aliyun-maven</id>
      <mirrorOf>central</mirrorOf>
      <name>阿里云公共仓库</name>
      <url>https://maven.aliyun.com/repository/public</url>
    </mirror>
  </mirrors>
</settings>
```

---

### 4. Docker 28+

本项目使用 Docker 运行测试所需的中间件（MySQL、Redis 等）。**Docker 是测试的强依赖**，请务必安装并配置好。

**下载链接：**

- [Docker Desktop 官网](https://www.docker.com/products/docker-desktop/)

**验证安装：**

```bash
docker --version
```

预期输出：

```
Docker version 28.x.x ...
```

**启动 Docker：**

安装完成后，确保 Docker Desktop 处于运行状态。

> 💡 **提示**：Testcontainers 需要 Docker 守护进程运行才能创建测试容器。

## 中间件（通过 Docker 运行）

以下中间件**无需本地安装**，测试时会自动通过 Testcontainers 创建 Docker 容器。了解这些配置有助于理解测试环境。

### MySQL 8.0

数据库服务。

**Docker 启动命令（参考）：**

```bash
docker run -d \
  --name mysql \
  -e MYSQL_ROOT_PASSWORD=root \
  -e MYSQL_DATABASE=spring_zhihu \
  -p 3306:3306 \
  mysql:8.0
```

### Redis

缓存服务，用于性能优化。

**Docker 启动命令（参考）：**

```bash
docker run -d \
  --name redis \
  -p 6379:6379 \
  redis:latest
```

### Kafka

消息队列服务（可选，用于异步任务）。

## 常见问题

### Q: 为什么测试运行时报 Docker 相关错误？

**A:** 确保 Docker Desktop 已启动，并且当前用户有权限访问 Docker 守护进程。

### Q: 可以使用 JDK 8 吗？

**A:** 不可以。本项目使用 Spring Boot 3.x，需要 JDK 17+。如果你想用 JDK 8，请使用 Spring Boot 2.x 版本。

### Q: 本地必须安装 MySQL 吗？

**A:** 不需要。测试时使用 Testcontainers 自动创建 MySQL 容器，无需本地安装。
