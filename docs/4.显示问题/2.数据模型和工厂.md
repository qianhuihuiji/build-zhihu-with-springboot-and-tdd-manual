# 数据模型和工厂

上一节的测试提醒我们 `QuestionMapper`、`QuestionExample`、`Question` 都不存在。所以我们接下来的工作，就是定义 `question` 数据表，并产生对应的 ORM 映射模型。

---

## 创建数据表

创建 Flyway 迁移脚本：
*src/main/resources/db/migration/V20260205__create_table_question.sql*：

```sql
CREATE TABLE `question`
(
    `id`           int unsigned NOT NULL AUTO_INCREMENT,
    `user_id`      int          NOT NULL,
    `title`        varchar(100) NOT NULL,
    `content`      text         NOT NULL,
    `created_at`   timestamp    NOT NULL,
    `updated_at`   timestamp    NOT NULL,
    PRIMARY KEY (`id`)
) ENGINE = InnoDB
  AUTO_INCREMENT = 1;
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int unsigned | 主键，自增 |
| `user_id` | int | 问题创建者 ID |
| `title` | varchar(100) | 问题标题 |
| `content` | text | 问题内容 |
| `created_at` | timestamp | 创建时间 |
| `updated_at` | timestamp | 更新时间 |

### 运行迁移

运行 Maven 的 `flyway` 插件命令生成表：

```bash
mvn flyway:migrate
```

执行成功后，数据库中会创建 `question` 表。

## 生成 ORM 映射

### 修改 Generator 配置

修改 `generatorConfig.xml` 的配置，改为生成 `question` 表：

```xml
<table tableName="question">
    <generatedKey column="id" sqlStatement="MySql" identity="true"/>
</table>
```

### 运行 Generator

运行 `Generator#main()` 方法生成对应的数据库映射文件，生成后会创建以下文件：

```
src/main/java
└── com.nofirst.spring.tdd.zhihu.startup.mbg
    ├── mapper
    │   └── QuestionMapper.java          # Mapper 接口
    └── model
        ├── Question.java                # 实体类
        └── QuestionExample.java         # 查询条件类

src/main/resources
└── mapper
    └── QuestionMapper.xml               # SQL 映射文件
```

## 新建模型工厂

重新导入缺失的类之后，我们应该立即运行测试。但是你会发现，`QuestionFactory` 类还不存在。

`xxxFactory` 类是我们为了测试方便而定义的模型工厂类，它会生产我们需要的模型对象。

### 创建工厂类

创建文件 *src/test/java/com/nofirst/spring/tdd/zhihu/startup/factory/QuestionFactory.java*：

```java
package com.nofirst.spring.tdd.zhihu.startup.factory;

import com.nofirst.spring.tdd.zhihu.startup.mbg.model.Question;
import java.util.Date;

public class QuestionFactory {

    public static Question createQuestion() {
        Date now = new Date();

        Question question = new Question();
        question.setUserId(1);
        question.setTitle("this is a question");
        question.setContent("this is content");
        question.setCreatedAt(now);
        question.setUpdatedAt(now);

        return question;
    }
}
```
