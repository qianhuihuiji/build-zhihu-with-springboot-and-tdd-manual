## 一、本章学习要点

### 1.1 筛选功能

我们学习了如何实现问题列表的筛选功能：

| 知识点 | 说明 |
|--------|------|
| 分页查询 | 使用 PageHelper 实现分页 |
| 条件筛选 | 使用 QuestionExample 动态构建查询条件 |
| 分类筛选 | 通过 slug 查询分类 ID，再筛选问题 |
| 用户筛选 | 通过用户名查询用户 ID，再筛选问题 |

### 1.2 筛选功能（二）

我们学习了如何添加更多筛选条件：

| 知识点 | 说明 |
|--------|------|
| 冗余字段 | 使用 answers_count 避免实时计算 |
| 数据一致性 | 创建/删除回答时更新计数 |
| 热度排序 | 使用 `orderByClause` 实现排序 |
| 未解答筛选 | 使用 `andAnswersCountEqualTo(0)` 筛选 |

### 1.3 推荐与举报

我们学习了如何实现投票功能：

| 知识点 | 说明 |
|--------|------|
| 代码复用 | 借鉴答案的赞同/反对功能实现 |
| 投票表设计 | 使用同一张 vote 表，通过 resource_type 区分 |
| 防止重复 | 先查询是否存在，存在则不插入 |
| 查询方法 | `isVotedUp()`, `upVotesCount()`, `isVotedDown()`, `downVotesCount()` |

### 1.4 关注问题

我们学习了如何实现关注功能：

| 知识点 | 说明 |
|--------|------|
| 订阅表设计 | 使用唯一约束防止重复订阅 |
| 关注功能 | 创建订阅记录 |
| 取消关注 | 删除订阅记录 |
| 权限控制 | 未登录用户返回 401 |

### 1.5 关注问题（二）

我们学习了如何实现通知功能：

| 知识点 | 说明 |
|--------|------|
| 事件机制 | 使用 Spring ApplicationEvent 解耦业务 |
| 事件监听 | 使用 `@EventListener` 监听事件 |
| 通知逻辑 | 查询订阅者并创建通知记录 |
| 排除回答者 | 订阅者中排除回答者本人 |

### 1.6 slug 转换

我们学习了如何实现翻译功能：

| 知识点 | 说明 |
|--------|------|
| 百度翻译 | 调用第三方 API 进行翻译 |
| 异步处理 | 使用 Kafka 避免阻塞主流程 |
| 配置属性 | 使用 `@ConfigurationProperties` 绑定配置 |
| 在线测试 | 使用 `@Tag("online")` 标记，可排除执行 |
| 路由匹配 | 使用正则匹配支持多种 URL 格式 |

## 四、技术要点

### 4.1 TDD 流程

```
┌─────────────────────────────────────────────────────────┐
│                  第八章 TDD 流程                         │
│                                                         │
│  1. 编写集成测试 ──────→ 2. 运行测试（失败）           │
│                               ↓                         │
│  4. 编写单元测试 ←──────── 3. 创建数据模型              │
│       ↓                       ↓                         │
│  7. 运行测试（通过） ←──── 5. 实现 Service 层           │
│       ↓                                                 │
│  8. 完善 Controller ──────→ 9. 运行全部测试            │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 4.2 筛选条件汇总

| 参数 | 说明 | 是否必填 | 实现方式 |
|------|------|---------|---------|
| `pageIndex` | 页码 | 是 | PageHelper |
| `pageSize` | 每页数量 | 是 | PageHelper |
| `slug` | 分类 slug | 否 | 查询分类 ID |
| `by` | 用户名 | 否 | 查询用户 ID |
| `popularity` | 热度排序 | 否 | orderByClause |
| `unanswered` | 未解答 | 否 | andAnswersCountEqualTo |

### 4.3 投票接口汇总

| 功能 | 推荐 | 举报 |
|------|------|------|
| 创建投票 | `POST /questions/{id}/up-votes` | `POST /questions/{id}/down-votes` |
| 取消投票 | `DELETE /questions/{id}/up-votes` | `DELETE /questions/{id}/down-votes` |
| 查询状态 | `isVotedUp(questionId)` | `isVotedDown(questionId)` |
| 查询数量 | `upVotesCount(questionId)` | `downVotesCount(questionId)` |

### 4.4 关注功能接口

| 功能 | 接口 | 说明 |
|------|------|------|
| 关注问题 | `POST /questions/{id}/subscriptions` | 创建订阅记录 |
| 取消关注 | `DELETE /questions/{id}/subscriptions` | 删除订阅记录 |

### 4.5 Spring 事件机制

```
┌─────────────────────────────────────────────────────────┐
│              Spring 事件机制流程                         │
│                                                         │
│  事件源 ──────→ 发布事件 ──────→ 事件总线              │
│                                         ↓               │
│                              ┌─────────────────┐       │
│                              │   事件监听器     │       │
│                              │  (可能有多个)   │       │

│                                         ↓               │
│                              执行具体业务逻辑           │

```

┌─────────────────────────────────────────────────────────┐

### Kafka 生产者

```java
@Component
public class CustomKafkaProducer {

    private KafkaTemplate<String, Object> kafkaTemplate;
    private TranslatorConfig translatorConfig;

    public void sendTranslateEvent(Question question) {
        TranslateSlugEvent event = new TranslateSlugEvent(question, new Date());
        kafkaTemplate.send(translatorConfig.getTopic(), event);
    }
}
```

### Kafka 消费者

```java
@Component
public class TranslateSlugEventConsumer {

    @KafkaListener(topics = "${translate.kafka.topic}", groupId = "${translate.kafka.group}")
    public void listen(TranslateSlugEvent event) {
        String slug = translatorService.translate(event.getQuestion().getTitle());
        questionMapperExt.updateSlug(event.getQuestion().getId(), slug);
    }
}
```
