## 本章学习要点

### 筛选功能

我们学习了如何实现问题列表的筛选功能：

| 知识点 | 说明 |
|--------|------|
| 分页查询 | 使用 PageHelper 实现分页 |
| 条件筛选 | 使用 QuestionExample 动态构建查询条件 |
| 分类筛选 | 通过 slug 查询分类 ID，再筛选问题 |
| 用户筛选 | 通过用户名查询用户 ID，再筛选问题 |

### 筛选功能（二）

我们学习了如何添加更多筛选条件：

| 知识点 | 说明 |
|--------|------|
| 冗余字段 | 使用 answers_count 避免实时计算 |
| 数据一致性 | 创建/删除回答时更新计数 |
| 热度排序 | 使用 `orderByClause` 实现排序 |
| 未解答筛选 | 使用 `andAnswersCountEqualTo(0)` 筛选 |

### 推荐与举报

我们学习了如何实现投票功能：

| 知识点 | 说明 |
|--------|------|
| 代码复用 | 借鉴答案的赞同/反对功能实现 |
| 投票表设计 | 使用同一张 vote 表，通过 resource_type 区分 |
| 防止重复 | 先查询是否存在，存在则不插入 |
| 查询方法 | `isVotedUp()`, `upVotesCount()`, `isVotedDown()`, `downVotesCount()` |

### 关注问题

我们学习了如何实现关注功能：

| 知识点 | 说明 |
|--------|------|
| 订阅表设计 | 使用唯一约束防止重复订阅 |
| 关注功能 | 创建订阅记录 |
| 取消关注 | 删除订阅记录 |
| 权限控制 | 未登录用户返回 401 |

### 关注问题（二）

我们学习了如何实现通知功能：

| 知识点 | 说明 |
|--------|------|
| 事件机制 | 使用 Spring ApplicationEvent 解耦业务 |
| 事件监听 | 使用 `@EventListener` 监听事件 |
| 通知逻辑 | 查询订阅者并创建通知记录 |
| 排除回答者 | 订阅者中排除回答者本人 |

### slug 转换

我们学习了如何实现翻译功能：

| 知识点 | 说明 |
|--------|------|
| 百度翻译 | 调用第三方 API 进行翻译 |
| 异步处理 | 使用 Kafka 避免阻塞主流程 |
| 配置属性 | 使用 `@ConfigurationProperties` 绑定配置 |
| 在线测试 | 使用 `@Tag("online")` 标记，可排除执行 |
| 路由匹配 | 使用正则匹配支持多种 URL 格式 |
